# Fall Guys PopTracker v1.0

First public release candidate of the Fall Guys Archipelago PopTracker.

## Includes
- 79 round/location checks grouped into seven categories.
- Progression crowns and Final Round Tickets.
- Larger, bold checklist text and clearer counter values.
- Gray inactive states for the ticket counters.
- Archipelago connection scripts and manual tracking fallback.

## Installation
Download `Fall-Guys-PopTracker-v1.0.zip` from the release assets, extract it into your PopTracker packs directory and open PopTracker.

## Known limitation
Live Archipelago synchronization, including seed-specific ticket requirements, has not been conclusively verified. This release should be treated as an initial public build until tested.
